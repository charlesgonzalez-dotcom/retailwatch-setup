RetailWatch — USB Setup Kit
===========================

FOLDER STRUCTURE
----------------
installers\
    python-3.11.exe        <-- Download from python.org (Windows 64-bit installer)
    ZeroTierOne.msi        <-- Download from zerotier.com/download

mediamtx\
    mediamtx.exe           <-- Copy from your existing mediamtx folder
    mediamtx-store.yml     <-- Auto-generated by configure-store script (ignore for now)

scripts\
    1-setup-backoffice.ps1 <-- Run at back office (as Admin)
    2-configure-store.ps1  <-- Run at the store


STEP-BY-STEP
------------

AT BACK OFFICE:
1. Drop python-3.11.exe into installers\
2. Drop ZeroTierOne.msi into installers\
3. Copy mediamtx.exe (and any .dll files) from your existing mediamtx folder into mediamtx\
4. Plug USB into new PC
5. Right-click scripts\1-setup-backoffice.ps1 -> Run with PowerShell (as Admin)
6. When done, go to zerotier.com -> Networks -> cf719fd5401745ac -> approve the new PC
7. PC is ready — unplug USB, box it up

AT THE STORE:
1. Plug in ethernet cable
2. Plug in USB
3. Run scripts\2-configure-store.ps1 (no admin needed)
4. Enter: store name, DVR IP, DVR password, camera count
5. Script starts mediamtx automatically
6. Verify cameras from your back-office PC
7. Reboot store PC to confirm auto-start
8. Done — one and done


NOTES
-----
- ZeroTier network ID: cf719fd5401745ac
- mediamtx runs hidden on startup automatically
- After store is set up, add its ZeroTier IP to your dashboard
